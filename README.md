# CS300---ANALYSIS-AND-DESIGN
datastructures and app design in c++
Throughout this course, I worked on projects that involved using different data structures, including vectors, linked lists, hash tables, and binary search trees. The main problem I was solving was how to organize, store, search, sort, and retrieve information efficiently. In the advising program project, I developed a program that loads course information from a CSV file, organizes the courses in a binary search tree, and allows users to view course lists and prerequisite information.

My approach was to learn how each data structure works and determine which one best fit the program's requirements. Understanding data structures is important because they affect how efficiently a program processes information. For example, a vector is useful for storing a collection of items, while a hash table can provide fast lookups and a binary search tree can keep information organized for searching and displaying in order.

One of the main roadblocks I encountered was loading and validating the course information from the CSV file. I received errors when the program could not correctly read the course numbers and titles. I worked through these problems by checking the file format, reviewing the code responsible for reading the data, and making corrections to how the program handled each line. Testing the program after making changes helped me identify the source of the errors and confirm that the solution worked.

This project expanded my approach to software design by teaching me to consider efficiency, organization, and the requirements of a program before choosing how to store information. Instead of focusing only on getting a program to work, I now understand the importance of selecting an appropriate data structure and considering how that choice affects performance as the amount of data increases.

My work on these projects also improved how I write maintainable, readable, and adaptable programs. I learned the importance of using meaningful variable names, separating program functions into manageable sections, and adding validation to handle incorrect input. I also gained experience testing individual functions and correcting errors without unnecessarily changing the rest of the program. These skills will help me develop software that is easier to understand, maintain, and expand when requirements change.
